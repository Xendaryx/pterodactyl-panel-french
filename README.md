# 🇫🇷 Traduction française de Pterodactyl Panel

Traduction française non officielle de **Pterodactyl Panel 1.15.1**.

Ce projet fournit une traduction française étendue du Panel Pterodactyl, incluant l'interface utilisateur ainsi qu'un grand nombre de messages internes.

## 📦 Version disponible

**Pterodactyl Panel : 1.15.1**

**Version de la traduction : v1.15.1-fr1**

➡️ [Télécharger la dernière version](https://github.com/Xendaryx/pterodactyl-panel-french/releases/latest)

## 🇫🇷 Éléments traduits

La traduction couvre notamment :

- Interface utilisateur
- Administration
- Gestion des serveurs
- Comptes utilisateurs
- Console et gestionnaire de fichiers
- Bases de données
- Sauvegardes et planifications
- Réseau et allocations
- Variables de démarrage
- API et clés API
- Authentification à deux facteurs
- Notifications
- Messages d'erreur et messages système
- Commandes Artisan
- Messages internes du Panel

Les termes techniques qui ne doivent pas être modifiés restent volontairement inchangés.

Cette traduction est destinée à **Pterodactyl Panel 1.15.1**.

La compatibilité avec d'autres versions n'est pas garantie. Une mise à jour officielle de Pterodactyl peut également remplacer certains fichiers concernés par cette traduction.
